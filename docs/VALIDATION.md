# Проверка собранной версии

Дата: 7 ноября 2026. Проверка выполнена на этом компьютере в пяти реальных Docker-контейнерах.

## Функциональные проверки

- Все пять контейнеров имеют статус healthy.
- Пройдены четыре сценария через Web Master: импорт → обучение → анализ → HTML/CSV.
- Для каждого из трёх датчиков обучена отдельная LSTM-модель на 120 эпохах; веса выбраны по минимальной ошибке временной валидации.
- Автоматические тесты: **6 passed** (pytest). Есть предупреждение об устаревающем алиасе BlockingPortal в зависимости Starlette/AnyIO; на функциональность оно не влияет.
- HTTP-проверка: пять health endpoint, последовательные батчи Collector, отказ некорректному CSV, импорт CSV без разметки, изменение/удаление собственных тестовых записей, скачивание HTML и 7 344 строк результатов CSV, отказ анализу до окончания калибровки.
- Все пять контейнеров пересозданы без удаления томов. Сохранились набор данных, шесть моделей и шесть запусков. Повторное применение сохранённых весов после перезапуска дало побитово одинаковые массивы оценок/решений и те же метрики.
- Из веб-формы успешно запущено и завершено обучение на пяти эпохах; техническая версия обозначена в списке отдельно. Анализ основной 120-эпоховой моделью также выполнен кнопкой интерфейса, ошибок в консоли браузера нет. Итоговый экран сохранён в `dashboard.jpg`.

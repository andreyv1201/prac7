Формат собственного CSV

Обязательные столбцы: timestamp,sensor,value. Необязательная разметка: label со значениями 0 или 1. Пустое значение обозначает пропуск.

timestamp,sensor,value,label
2025-06-13T00:00:00Z,temperature-1,23.5,0
2025-06-13T00:10:00Z,temperature-1,23.7,0

Нужны регулярный шаг времени и достаточно длинные отдельные периоды для обучения, настройки порога и анализа.

Как проходит анализ

Collector выдаёт пакет измерений. Web Master передаёт его в Storage. ML Service получает данные через API хранилища, обучает модель и сохраняет результаты. Этот интерфейс обращается к Web Master.

Модели, данные и история сохраняются в отдельных постоянных томах Docker. Журнал запросов ведётся каждым сервисом.
